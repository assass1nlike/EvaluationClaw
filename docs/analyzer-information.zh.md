# Analyzer 获取的信息

Analyzer 在主评测完成后，根据基准题目、模型结果和验证轮次历史提出能力假设，并据此请求新的验证题。它收到的信息分为默认上下文和按需读取的完整证据。

题目信息包括题目内容、所属维度、题型、难度、选项、参考答案、参考轨迹和评分规则。agent 题目还会附带环境契约摘要，包括镜像、网络与资源限制、执行命令、评测配置和环境文件路径。完整题目及环境详情可以按需读取。

模型结果按目标模型和题目记录，包含得分、错误信息、评分理由及原生指标。相同的错误或评分理由只提供一份正文，其余位置引用它。模型原始回答默认保留开头和结尾片段，完整作答可按需读取。

上下文还包括主评测的汇总分数、基准目标和维度定义，以及每轮验证的分析、证据判定、任务设计、题目和运行结果。大题集使用有总量上限的概览，另提供全部题目与结果的索引，保留得分、执行错误标记和已有证据判定，包括成功作答的题目。索引过大时也可分页读取；未显示的内容不代表不存在，未审阅的部分不能算作已完成覆盖。

工具对话达到上下文预算时，完整对话先留档，再以概览接续。归档保留原始消息和工具结果，可恢复早期假设、证据与未解决问题；接续时从完整消息边界开始，不保留孤立的工具调用或结果。

Analyzer 可以使用以下只读工具：

- `read_analysis_context` 按来源和 JSON 路径分页读取完整分析输入、长工具回复或归档对话；
- `read_item_evidence` 按模型、题目和迭代读取完整题目、作答轨迹、评分理由或 QC；
- `list_run_artifacts` 查找当前运行保存的证据文件；
- `read_run_artifact` 分页读取指定证据文件。

这些工具只能访问当前分析的快照或当前运行目录，有明确的分页位置。QC 不进入默认上下文；需要判断题目或评分是否有问题时，可读取完整证据，避免把环境和评测器错误归为模型弱点。
