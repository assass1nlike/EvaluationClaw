高并发时，Docker默认地址池可能因每个网络分配较大的子网而耗尽。无需改daemon配置，可指定供框架使用的IPv4池：

```bash
export EVALCLAW_DOCKER_NETWORK_POOL=10.254.0.0/16
```

这是本机专用 Docker 的地址池；其它机器应选择其网络管理员允许的空闲地址范围。框架为每个隔离网络申请独立/27子网（30个主机地址），在同一账号下通过跨进程文件锁协调，避开现有Docker网段及非默认主机路由。每道题仍保留独立网络，内部网络仍不可访问外网，模型网关独立接入出口网络。池用尽时报错，不回退到共享网络或关闭隔离。

此设置适用于外部harness的模型网关网络，以及内存预算Docker客户端创建的网络。不会更改已有网络，也不会为其它应用配置默认地址池。没有显式设置时沿用Docker默认分配。
